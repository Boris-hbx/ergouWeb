# TEST-analytics

覆盖用户行为分析后台，包括 T-218 后端聚合、T-219 前端采集、T-220 admin 看板页。

## T-220 Admin 行为看板

### A1 管理入口
- 前置：登录 owner/admin 用户。
- 操作：进入「管理」页面。
- 预期：左侧出现「📈 行为」分页；点击后打开「行为分析」页面。

### A2 默认加载
- 前置：`behavior_events` 有近 7 天数据。
- 操作：打开「行为」分页。
- 预期：并行拉取 overview/top-targets/feature-usage/dwell/users/trail；展示活跃用户、会话数、总事件、人均事件四张概览卡。

### A3 时段图表
- 前置：overview 返回 `by_hour` 24 个桶。
- 操作：打开「行为」分页。
- 预期：Chart.js 柱状图显示 00:00-23:00 事件分布；Chart.js 未加载时显示占位，不白屏。

### A4 点击排行
- 前置：top-targets 返回点击数据。
- 操作：查看「按钮点击排行」。
- 预期：按点击数降序显示目标 label/id、横向条和次数；无数据时显示「暂无点击数据」。

### A5 功能使用与停留
- 前置：feature-usage/dwell 返回 route 数据。
- 操作：查看「功能使用与停留」「停留排行」。
- 预期：展示 pageviews、总停留、平均停留、中位停留、样本数；停留时间格式化为秒/分钟/小时。

### A6 用户分群钻取
- 前置：users 返回至少两个用户。
- 操作：点击用户表中的「钻取」。
- 预期：用户筛选下拉同步到该用户，并刷新概览、排行、功能使用、停留和轨迹。

### A7 时间筛选
- 操作：切换今天/近 7 天/近 30 天/自定义日期。
- 预期：请求带 `from`/`to` 参数；自定义日期只在选择日期后刷新；页面不丢失用户筛选。

### A8 行为轨迹
- 前置：用户有事件序列。
- 操作：选择某用户或打开默认全量视图。
- 预期：轨迹按 `client_ts` 升序展示 event_type、target/route、dwell；无用户或无数据时显示空态。

### A9 错误态
- 前置：任一 analytics 接口返回失败或网络错误。
- 操作：打开「行为」分页。
- 预期：显示「加载失败，请重试」；控制台有 `[admin-analytics]` 错误日志；不影响其他 admin 分页。
