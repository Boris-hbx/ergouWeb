# TEST-praxis-layout — Praxis v0.2.1 驾驶舱布局重构 (T-290)

> 纯前端布局重构。UI 基准 = `docs/praxis-preview.html`（严格对照）。桌面 only，无后端/API 改动。

## 布局

| # | 场景 | 预期 |
|---|------|------|
| L1 | 顶部工具条 | 一条工具条取代原 3 行大卡：`🧭 Praxis·经营自己` + 今日经营(紧凑块+状态角标) + 记录回看(紧凑块) + 右侧健康度圆环 |
| L2 | 空白带利用 | 原顶部浪费的空白带被工具条填满，八板块+关系弧整体上移 |
| L3 | 八板块 tab 行 | 工具条下紧接一行 8 个 tab（名称 + 评分环，颜色按 ≥75绿/50–74黄/<50红），当前板块高亮 |
| L4 | hover 理念 | tab hover 弹出该板块理念气泡（深色浮层） |
| L5 | 内容区占满 | 板块内容区 `min-height: calc(100vh - 240px)`，关系同心弧明显变大 |
| L6 | 图例 | 关键关系板块底部有五态图例（最近深聊/仅浅联系/超周期/建议本周/有风险） |
| L7 | 板块理念行 | 内容区标题下有一行当前板块理念引文 |

## 交互不变（回归）

| # | 场景 | 预期 |
|---|------|------|
| R1 | 今日经营 | 点工具条「今日经营」→ 打开今日经营页（T-285）；返回回驾驶舱 |
| R2 | 记录回看 | 点工具条「记录回看」→ 打开记录回看页（T-286）；返回回驾驶舱 |
| R3 | 状态角标 | 今日经营角标随记录状态显示 未记录/已记录/已分析 |
| R4 | 健康度 | 点健康度圆环 → 手动输入 0–100，圆环数字+颜色即时更新 |
| R5 | tab 切换 | 点其它板块 tab → 内容区切占位面板（标题/理念更新，隐藏计数/新建/图例）；点回关键关系恢复弧 |
| R6 | 关系人 CRUD | 新建/选节点/编辑/删除/交流记录（T-283/T-287）功能不受布局改动影响 |
| R7 | 视图互斥 | 今日经营/记录回看子页打开时，工具条+驾驶舱整体隐藏，不残留 |

## 边界

- 桌面 only（viewport ≥ 1280），不写移动端 @media。
- 布局切换静默，无入场大动效（守动效分级）。
- 无后端/API/表改动。
