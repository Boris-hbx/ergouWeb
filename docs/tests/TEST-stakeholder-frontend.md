# TEST-stakeholder-frontend

覆盖 T-223：工作 Hub 干系人前端入口、独立页、表格/看板/分布三视图、详情抽屉和新建表单。

## T-223 前端

### S1 Hub 入口
- 操作：进入工作 Hub，点击「干系人」卡片。
- 预期：隐藏工作 Hub 和任务表，显示干系人独立页；刷新后可恢复干系人页。

### S2 数据加载
- 操作：打开干系人页。
- 预期：并行请求 `/api/work/stakeholder-columns` 和 `/api/work/stakeholders`；加载失败时显示 toast 并记录 `console.error('[stakeholder]', err)`。

### S3 表格视图
- 操作：查看表格视图，搜索姓名/部门/地域/事项。
- 预期：列头来自 stakeholder column 配置；multi 字段显示 chip；搜索胶囊显示「N 人命中 / 共 M 人」；行点击打开详情抽屉。

### S4 看板视图
- 操作：切到看板，选择按部门/地域等 select 字段分列，拖卡到另一列。
- 预期：卡片显示姓名、职务、地域、管理方式摘要；拖卡 patch 对应 select 字段；不套用任务 status/完成链。

### S5 分布视图
- 操作：切到分布，切换任意 select/multi 维度。
- 预期：气泡大小按人数缩放，颜色为中性；multi 字段一个人可落多个卡，显示 `+N`；未填分组置末。

### S6 详情与新建
- 操作：点击行/卡打开详情，修改字段保存；点击「+ 新建干系人」创建。
- 预期：姓名必填；multi 字段支持逗号/分号输入；保存走 PATCH，新建走 POST；删除走软删除接口并从前端列表移除。

### S7 列设置
- 操作：点击「⚙ 列设置」，改列名/类型/宽度，给 select/multi 增删改选项，拖动调整顺序，新增并删除自定义列。
- 预期：批量变更走 `PUT /api/work/stakeholder-columns`；新增走 `POST /api/work/stakeholder-columns`；删除自定义列走 `DELETE /api/work/stakeholder-columns/{key}`；内置列显示锁定不可删；保存后表格/看板/分布同步刷新。

## T-230 抽屉关闭 + 相关工作标签

### S8 详情抽屉保存后关闭
- 操作：点击干系人打开右侧详情抽屉，改字段后点「保存」。
- 预期：保存成功后抽屉**自动关闭**，列表/表格/看板/分布同步显示新值。

### S9 保存失败不关闭
- 前置：mock PATCH 返回 `{success:false}` 或网络失败。
- 操作：详情抽屉点「保存」。
- 预期：抽屉**保持打开**，弹出错误提示（toast），`console.error('[stakeholder] update failed')`（网络失败时）。

### S10 「接口事项」改名为「相关工作标签」
- 操作：查看表头、详情字段名、新建表单字段名、看板/分布维度选择、列设置。
- 预期：原 `liaison` 列（默认名「接口事项」）全前端可见处显示「相关工作标签」；后端字段 key 仍为 `liaison`，不做 DB 迁移。

### S11 相关工作标签多值输入
- 操作：在详情/新建表单的「相关工作标签」textarea 输入 `经费, 招生` 或多行（经费\n招生）。
- 预期：旁边有提示「可用逗号或换行分隔多个标签」；保存后解析为多个标签，已 trim、去空、去重；表格以 chip 展示，看板/分布按多值统计。

## T-229 关系图视图

### S12 关系图入口与三种模式
- 操作：进入干系人页，点击「关系图」，在「按部门 / 按事项 / 按地域」之间切换。
- 预期：关系图不新增后端请求，直接使用已加载的干系人数据；按部门连接 `team` 与人员，按事项连接 `duty` + `liaison`（前端显示为「负责事项」+「相关工作标签」）与人员，按地域连接 `region` 与人员；缺部门、缺事项、缺地域的人员都进入「未填」节点，不被跳过。

### S13 图谱交互
- 操作：hover 任一节点，点击维度节点，点击人员节点。
- 预期：hover 高亮相邻节点和边、弱化无关节点；点击维度节点后右侧显示关联人员列表；点击人员节点打开现有详情抽屉。

### S14 搜索与空状态
- 操作：搜索姓名/部门/事项/地域；清空全部干系人后查看关系图。
- 预期：搜索结果在关系图中保持可见并高亮匹配节点；没有干系人时提示先新建；字段缺失进入「未填」节点，不报错。

## T-231 关系图可用性打磨

### S15 行动面板
- 操作：在关系图中点击部门/事项/地域维度节点。
- 预期：右侧面板显示关联人数、是否存在未填人员、单点联系人风险、枢纽人员提示，并保留可点击打开详情的人员列表。

### S16 人员节点面板与状态编码
- 操作：点击人员节点，查看右侧面板；对有/无管理方式或频率的人员对比节点样式。
- 预期：右侧面板显示部门、地域、职务、负责事项、相关工作标签、关系说明、管理方式/频率，并有打开详情入口；有跟进节奏的人员节点有轻量标记，人员节点大小保持稳定。

### S17 relation 文本生成关系线索边
- 前置：干系人 A 的 `relation` 写入系统中已有的干系人姓名 B / C。
- 操作：进入关系图，hover 或点击 A、B、C 任一人员节点。
- 预期：A 与 B/C 之间生成虚线、浅色的关系线索边，hover/点击时强调；右侧面板显示「可能的触达路径/关系线索」，并标明来源是 `relation` 文本匹配。

### S18 relation 未匹配不乱连线
- 前置：某人 `relation` 写入不在干系人列表中的姓名或普通文本。
- 操作：进入关系图并点击该人员节点。
- 预期：不生成错误边、不报错；右侧面板仅展示原始关系说明。

## T-233 关系图连线视觉质感

### S19 主关系边曲线与端点
- 操作：进入关系图，分别切换「按部门 / 按事项 / 按地域」。
- 预期：主关系边使用柔和曲线或折中曲线，不再是硬直线；线条从节点边缘附近连接，不穿过节点文字中心。

### S20 hover/选中层级
- 操作：hover 或点击任一维度/人员节点。
- 预期：相关主边变亮并略加粗，非相关边明显弱化；节点高亮和 T-231 右侧行动面板不回退。

### S21 relation 线索边层级
- 前置：存在可匹配到其他干系人姓名的 `relation` 文本。
- 操作：查看关系图并 hover/点击相关人员节点。
- 预期：relation 线索边保持虚线、浅色、细线，active 时也弱于主关系边；不喧宾夺主。
