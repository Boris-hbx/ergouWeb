# TEST-praxis-review — Praxis 记录回看 (T-286 / SPEC praxis §6)

> 纯前端，复用 `GET /api/praxis/journal`（from/to 走后端，board/type 前端筛），**无新表/新端点**。
> 只读：查看历史今日经营记录，回答"我是不是又在重复同一个模式"。

## 入口 / 视图切换

| # | 场景 | 预期 |
|---|------|------|
| V1 | 入口 | Praxis 驾驶舱「今日经营」入口下方有「📚 记录回看」入口 |
| V2 | 打开 | 点入口 → 记录回看页（筛选条 + 左列表 + 右详情）；驾驶舱/今日经营入口隐藏 |
| V3 | 返回 | 「← 驾驶舱」回八板块；今日经营状态徽标刷新 |
| V4 | 互斥 | 今日经营页与记录回看页互斥；进任一页另一页隐藏；Praxis.open() 复位回驾驶舱 |

## 列表 / 筛选

| # | 场景 | 预期 |
|---|------|------|
| L1 | 列表 | 历史记录按 `entryDate` 倒序；每行=日期 + 类型徽标 + 摘要/原文摘要 + 板块 chip；计数「共 N 条」 |
| L2 | 无结构化 | 未分析的记录也显示（标题回退到 rawText 摘要） |
| L3 | 日期筛选 | 设「从/到」→ 回服务端按 entry_date 范围重拉 |
| L4 | 板块筛选 | 选某板块 → 前端筛 `structured.boards` 含该板块的记录 |
| L5 | 类型筛选 | 选某类型 → 前端筛 `structured.value` 等于该类型 |
| L6 | 组合筛选 | 日期 + 板块 + 类型可叠加 |
| L7 | 重置 | 「重置」清空四个筛选条，重新全量加载 |
| L8 | 空结果 | 无匹配显示「没有匹配的记录」 |

## 详情（只读）

| # | 场景 | 预期 |
|---|------|------|
| D1 | 选中 | 点某行 → 右侧详情：日期 + 原文(保留换行) + 结构化卡(类型/摘要/板块/事件/风险/明日调整) |
| D2 | 高亮 | 选中行有高亮态 |
| D3 | 只读 | 详情不可直接编辑 |
| D4 | 编辑入口 | 「编辑」→ 跳今日经营页并定位到该天日期（`PraxisJournal.open(date)`），可改后保存 |
| D5 | 未分析 | 没 structured 的记录详情提示「这条还没分析过」 |

## 边界

- 后端无改动：仅消费 `GET /api/praxis/journal`（已支持 `?from=&to=&limit=`）。
- 百条级前端筛 board/type 足够；日历视角、板块/标签反复出现统计留 v0.3（spec §6）。
- 加载失败：toast「记录回看加载失败」+ `console.error`，列表清空不崩。
