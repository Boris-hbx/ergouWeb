设计说明（PM 草稿）

  • 形态：上图（气泡总览）+ 下卡（责任人卡片墙），方案 1「上图下卡片」。脑图不做，理由：节点 > 20 容易乱，且 Boris 实际需求是「谁负责什么 / 谁有逾期」而非「拓扑关系」。
  • 气泡颜色：红=含逾期 / 橙=含 P0 / 紫=正常 / 灰=仅低优；气泡大小：按任务数（min 56px → max 110px，对数缩放避免大户压制小户）。
  • 头像配色：4 色调色板（紫 / 青绿 / 暖橙 / 蓝），按 assignee 字符串 hash 取色，同一人在所有视图色一致。
  • 时间 Tab 叠加：本视图遵循全局 Tab。切「今日」= 只显示今日任务的责任人和任务（含逾期）；切「全部」回到完整视图。
  • 未指派任务：单独显示一张「未指派」卡，置于最末。
  • 拖拽转交：复用 work-board 已有拖拽逻辑。拖任务卡到另一人 → 弹确认「将『XX』转交给 YY 吗？」→ 确认后 PATCH /api/work/tasks/{id} {"assignee":"YY"}。
  • 点击任务：MVP 走现有的列设置/编辑 modal 复用；本稿仅模拟划掉。
  • 实现成本：纯前端，复用 work-board 拖拽 + 现有 assignee 数据，无需新增 API。预计 1 个新文件 work-person.js + work.css 加一段。
