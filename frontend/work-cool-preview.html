5 个 Cool 动效（皆已可玩）

1. 30 天负载心电图 — 全局俯瞰一秒钟

  • 顶部一条 30 个柱子，每柱 = 一天任务数；今天高亮 + 发光脉动
  • 含逾期的天用红底；hover 上浮 + 显示当天数字 tooltip
  • 点柱跳到那天的过滤视图——一眼看出哪天忙、哪天空
  • 实用：避免做计划只看本周，看不见三周后的雪崩；像 GitHub 贡献图但是任务版

2. 时间 Tab 切换 — Spring 滑动指示条

  • 底部紫色指示条用 spring 缓动滑到目标 Tab（不是 fade，是物理感的滑动）
  • 切 Tab 时任务行 stagger 动画依次淡入（FLIP-lite），不是一刀切的 redraw
  • 实用：数据变化看得到过程，知道是"筛选"而不是"换页面"

3. ✓ 完成时的彩纸庆祝（严格走进度弹窗确认流程）

  • 流程：点 ☐ → 弹 openProgressDialog(slider) → 用户拖到 100% → 按钮变「确定完成」+ 渐变紫 → 点确认 → 二次确认弹层 → 才彩纸 + spring + 行温柔淡出
  • 不允许：点 ☐ 直接完成（这是 spec § 7.1 percent 行 + T-095 已落地的规则，与 todo 共享同一份 openProgressDialog）
  • 彩纸：14 片小方片从复选框位置喷出，6 色随机、旋转随机、x 漂移随机；CSS animation 1.4s 飘下消失
  • checkbox 用 spring 弹（cb-pop animation）；✓ 划入用 transform draw 动画；进度条用紫渐变 + spring 缓动伸长
  • 实用：心理学上「完成」需要正反馈才能形成习惯；二次确认避免误触；Things 3 的核心 cool 点

4. ⌘K 命令面板 — 已否决（Boris 决定不做）

  • 键盘党命令面板不符合 Boris 使用习惯，本次不做
  • HTML 与 JS 代码已从设计稿移除；若后续需求变化再单独立项

5. 拖拽的物理感 — 卡片"飘起来"

  • 拖任务行：scale 1.02 + 微旋 0.5° + 投影加深 + 背景变白
  • 感觉"拿起来一张牌"，不是"光标拽个矩形"
  • drop 时其他行 spring 让位（不是瞬移）
  • 实用：拖拽更稳更准（视觉反馈强 → 不容易拖错）
性能与实施成本：所有动效用 CSS animation / transition，不用 motion 库；GPU 加速属性（transform / opacity）；总 CSS 增量 ~150 行 + JS ~80 行。不影响后端、不动数据结构。可作为现有 4 视图的通用增强。

没做但值得考虑（下一波）：

  • Focus Mode（F 键）：选中任务按 F → 全屏聚焦该任务 + 周围淡出 + 仅显示标题+进度 + 大字体；按 Esc 退出。仪式感拉满，配合番茄钟
  • 气泡 → 卡片 morph：人员视图点气泡时气泡变形飞到卡片位置（FLIP / Shared Element），视觉连续
  • 阿宝逐字生成 task-card：阿宝创建任务时卡片从右侧滑入 + 标题逐字打出（像 ChatGPT streaming）
  • 拖到日历的虚线轨迹：拖任务时一条虚线从源到鼠标，过去日期虚线变红
