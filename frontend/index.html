安全与隐私

  • 密码经 Argon2id 加密存储，任何人（包括开发者）都无法查看
  • 全程 HTTPS 加密传输，启用严格浏览器安全策略
  • 你的数据与其他用户完全隔离
  • 登录保护：连续输错密码将临时锁定，防止暴力破解
  • 注册流控：每日自动通过名额有限，超出后需管理员审批，防止滥用
  • 文件访问严格校验路径，防止越权读取
  • 二狗由 Claude AI 驱动，对话通过加密连接处理
🛡 防攻击措施

已针对以下攻击场景部署多层防护：

  • SQL 注入全部使用参数化查询
  • 跨站脚本 (XSS)内容安全策略 (CSP) + 输入过滤
  • 暴力破解IP 限速 + 账户锁定双重防护
  • 中间人攻击HTTPS 强制 + HSTS 策略
  • 点击劫持X-Frame-Options DENY
  • 会话劫持HttpOnly + Secure + SameSite Cookie
  • 路径穿越文件名严格校验，禁止 ../ 遍历
  • 注册滥用每日限额 + 管理员审批机制
