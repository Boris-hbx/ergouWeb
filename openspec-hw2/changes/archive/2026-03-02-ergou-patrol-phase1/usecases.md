## 用例

### UC1: 二狗自动出场

**角色**: 用户（手机端）

**前提**: 用户在非阿宝聊天页面，且巡游开关开启、非 reduced-motion、冷却已结束

**流程**:
1. 用户停止操作 8 秒（idle 阈值）
2. tab icon 微泛光晕（0.5s）
3. tab icon 开始变淡（实心 → 半透明）
4. icon 边缘探出半个爪印（0.3s）
5. 第一个完整爪印落在 tab 栏上方（弹性落地 + 涟漪）
6. 第二个爪印（另一只脚）
7. 二狗开始行走，左右交替踩爪印

**验收**: 用户不操作 8 秒后自然看到爪印从 tab icon 方向出现

---

### UC2: 二狗行走巡游

**角色**: 用户

**前提**: 二狗已出场，处于 walk 状态

**流程**:
1. 二狗按步态参数（步幅、左右偏移、外旋角度）交替踩爪印
2. 每个爪印落地时播放弹性 scale 动画 + 涟漪扩散
3. 高端设备：爪印颜色取脚下元素的 computed style 主色调（放置瞬间查一次）
4. 低端设备：爪印使用固定主题色
5. 旧爪印在 1.5s 后蒸发消失
6. 屏幕上最多同时 8 个爪印

**验收**: 爪印轨迹自然、流畅、不阻塞用户操作

---

### UC3: 点击退场（退场 A）

**角色**: 用户

**前提**: 二狗正在巡游

**流程**:
1. 用户点击页面上的任何可交互元素
2. 最新的爪印先消失，依次到最远的（波浪式，间隔 50ms）
3. 总退场时长约 0.3s
4. 状态机回到 home
5. 触发冷却计时（3 分钟）

**验收**: 点击后爪印以波浪方式快速消失，零干扰

---

### UC4: 滚动退场（退场 E）

**角色**: 用户

**前提**: 二狗正在巡游

**流程**:
1. 用户开始滚动页面
2. 所有爪印同时快速 fade out（0.2s）
3. 状态机回到 home
4. 滚动停止后重新开始 idle 计时（不触发冷却，允许快速重新出场）

**验收**: 滚动瞬间爪印消失，滚动停止后可重新出场

---

### UC5: Modal 退场（退场 B）

**角色**: 用户

**前提**: 二狗正在巡游

**流程**:
1. 用户打开任何 Modal / 弹窗
2. 所有爪印同时 fade out（0.2s）
3. 状态机回到 home
4. Modal 关闭后重新 idle 计时

**验收**: Modal 打开时爪印立刻消失，不干扰 Modal 交互

---

### UC6: Tab icon 联动

**角色**: 用户

**前提**: 巡游开关开启

**流程**:
1. 二狗在家：tab icon 实心双爪，opacity 100%
2. 二狗探头中：tab icon 开始变淡（100% → 50%）
3. 二狗巡游中：tab icon 变为淡空心轮廓（opacity 30%, stroke-only）
4. 二狗回家中：tab icon 轮廓逐渐填充（30% → 100%）
5. 回家落定：tab icon 脉冲（scale 1→1.15→1, 0.3s）

**验收**: tab icon 状态始终与二狗巡游状态同步

---

### UC7: Pause → Rest 子状态

**角色**: 用户

**前提**: 二狗正在行走

**流程**:
1. 行走路径走完，进入 pause 状态
2. pause 超时后继续下一段行走
3. 如果长时间 pause（无新路径），进入 rest
4. rest 状态：爪印 opacity 降到 0.3、scale 微缩 0.95
5. 最后两对爪印进入呼吸动画（opacity 0.3↔0.35 循环）
6. 用户恢复操作或新 idle 触发时退出 rest

**验收**: 二狗走完路后自然停下、趴下，视觉上有"安静了"的感觉

---

### UC8: 设置页开关

**角色**: 用户

**前提**: 用户进入设置页

**流程**:
1. 设置页显示"二狗巡游"开关
2. 默认开启
3. 关闭后立刻退场（如果巡游中），后续不再出场
4. 开启后下次 idle 时出场
5. 设置存 localStorage

**验收**: 开关即时生效，设置跨页面持久化

---

### UC9: 仅移动端

**角色**: 用户（桌面端）

**前提**: 用户在桌面浏览器访问

**流程**:
1. 页面加载时检测设备
2. 桌面端跳过巡游系统初始化
3. 不创建 patrol-layer、不绑定事件、不启动 IdleDetector

**验收**: 桌面端零开销，无任何巡游相关 DOM 或事件监听

---

### UC10: 冷却机制

**角色**: 用户

**前提**: 二狗刚退场

**流程**:
1. 退场后触发 3 分钟冷却
2. 冷却期间 idle 不触发出场
3. 冷却结束后，下一次 idle 必定出场
4. 滚动退场不触发冷却（允许快速重新出场）

**验收**: 退场后不会反复出没，但滚动停止后允许快速重现
