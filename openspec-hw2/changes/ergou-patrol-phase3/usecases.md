## Use Cases

### UC-1: 任务完成时踩已阅爪印
- **触发**: 用户在 Todo 页完成一个任务（进度设为 100% 或直接标记完成），且二狗正在巡游（walk/pause/rest 状态）
- **行为**: 二狗在被完成的任务卡片上方踩一个特殊"已阅"爪印（比普通爪印稍大，带微光效果）
- **约束**: 仅巡游中触发；如果二狗在 home 状态则不反应

### UC-2: 象限最后任务完成时踩 ✓ 图案
- **触发**: 用户完成某象限最后一个未完成任务，且二狗正在巡游
- **行为**: 二狗快速跑到该象限区域，踩出 ✓ 形状的爪印图案（3-4 个爪印组成对勾形）
- **约束**: 仅巡游中触发；如果象限仍有其他未完成任务则不触发

### UC-3: Jelly pill 滑动时跟随跑动
- **触发**: 用户切换底部 nav tab，jelly pill 开始滑动动画
- **行为**: 二狗沿 jelly pill 的滑动方向快速移动 2-3 步（像是追着 pill 跑）
- **约束**: 仅巡游中触发；切到阿宝 tab 时按收敛逻辑退场（已有），不触发跟随

### UC-4: 聊天状态 logo 联动
- **触发**: 用户在阿宝 tab 发送消息后等待 AI 回复（思考中状态）
- **行为**: 底部 nav 阿宝 logo 显示呼吸灯效果（缓慢脉冲），AI 回复完成后停止
- **约束**: 不依赖巡游状态，任何时候聊天中都生效

### UC-5: 二狗不在巡游中时不干扰
- **触发**: 任务完成、jelly pill 滑动等事件发生，但二狗在 home 状态（未巡游）
- **行为**: 不产生任何视觉效果
- **约束**: 所有交互行为（UC-1/2/3）只在 canPatrol 为 true 时触发

### UC-6: 交互不阻塞用户操作
- **触发**: 二狗响应交互事件
- **行为**: 所有交互动画通过 pointer-events:none 层展示，不阻塞用户继续操作
- **约束**: 动画时间 <500ms，不干扰原有 UI 反馈（toast、line pulse 等）
