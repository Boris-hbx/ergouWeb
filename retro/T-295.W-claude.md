## 实现要点（对照 §11.8 ①–⑥）

- **① 正圆扇形**：废弃椭圆 `arcPath(rx,ry)` 的两段贝塞尔；改用极坐标 + SVG `A r r` 单半径圆弧命令 `arcSeg(r)`。三层同一圆心（在「我」`CX=58,CY=248`），只在右前方张开 `SPAN=70°`（`A0=-35 / A1=35`），半径 150 / 278 / 415 依次变大。
- **② 分区散落**：彩色弧只作每层外边界线；人由 `layerPositions()` 在分区内沿「同心排」(角度) + 「排半径」(远近) 2D 铺开，不再串弧上。
- **③ 分区固定**：三层 rBound / rows 恒定，某层 1 人也占满分区、不缩。
- **④ 容量软上限**：圈一≤5 / 圈二≤15 / 圈三≤30；超额不挤爆（余数并入末排），并在弧上方渲染温和提示 `.praxis-cap-hint`（"圈一建议 ≤5 人，你已 N 人"）。
- **⑤ 防重叠**：圆点 + 名字（点上方居中）都避让。**修正了原型的一处缺陷**——原型 `shift + 越界回卷` 会让满员奇数排的末点回卷到与首点重合（dist=0）。改为「每排 c 点落在 c 等分子弧中点」的分布：始终在 `[lo,hi]` 内、绝不重合，且各排 c 不同（2/3、4/5/6、9/10/11）天然错位。数值校验：满员 50 点全局最小点距 **36px**（点 r5.5），无重叠。
- **⑥ 中性代号**：显示名 `core→圈一 / important→圈二 / normal→圈三`（弧标签 + 人物信息层级 pill 同步）；周期语义（圈一约7天/圈二约30天/圈三不强制）移到 pill 的 `title` tooltip，不进弧标签。
